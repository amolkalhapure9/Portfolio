01.About me

Hi! I'm Amol, a Software Engineer at Bitwise Global, where I build and maintain backend services and REST APIs with Java and Spring Boot. Day to day I design SQL schemas, tune queries, debug production issues and review code with my team.

Outside work I build things to learn how larger systems fit together: a microservices platform with an API gateway, service discovery and circuit breakers; an event-driven fitness tracker on Kafka; and a real-time skill-exchange app with WebSockets and Redis caching.

I hold a B.E. in Information Technology from P.E.S. Modern College of Engineering, Pune. When I'm not coding, I'm probably playing cricket, swimming, reading or travelling.
